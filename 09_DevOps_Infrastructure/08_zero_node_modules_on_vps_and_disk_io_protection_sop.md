# QUY CHUẨN VẬN HÀNH ZERO-NODE-MODULES & CHỐNG NGHẼN DISK I/O
## DÀNH CHO DEVOPS ENGINEER & CLOUD OPS

> [!CAUTION]
> Chạy lệnh `npm install` hay `yarn add` trong môi trường VPS đa khách thuê (Multi-tenant) là nguyên nhân số 1 gây tràn RAM (OOM) và nghẽn IOPS ổ đĩa. Quy trình này nghiêm cấm việc chạy npm trên máy chủ VPS backend.

---

## 1. BẢNG DỰ TOÁN NĂNG LỰC VPS TIÊU CHUẨN (1 CPU - 2GB RAM)

| Tham Số Kỹ Thuật | Nếu Cho Chạy `npm install` | Áp Dụng Chuẩn Zero-Load Virtual Code |
| :--- | :--- | :--- |
| **Số dự án chịu tải tối đa** | 3 – 5 dự án | **Hơn 3,000 dự án** |
| **Mức tiêu hao RAM** | 1.8GB – 2.0GB (Nguy cơ chết VPS) | **Ổn định ở 80MB – 150MB** |
| **IOPS Ổ cứng** | 100% bão hòa khi giải nén package | **Gần như 0 IOPS (Chỉ đọc/ghi DB)** |
| **Thời gian khởi động hệ thống** | 5 – 10 phút tải dependencies | **Dưới 1 giây (Docker Alpine cực nhẹ)** |

---

## 2. GIÁM SÁT SỨC KHỎE MÁY CHỦ
Endpoint `/api/health` của hệ thống liên tục đo lường:
- `memory.rssMb`: Dung lượng bộ nhớ thực tế đang dùng.
- `database.totalProjects`: Số lượng dự án đang lưu trữ trong JSONB/PostgreSQL.
- `cache.mode`: Tình trạng cache Redis.
- Khi dung lượng dự án tăng lên, bộ nhớ RAM chỉ tăng theo hàm tuyến tính siêu nhỏ (vài chục KB mỗi project).
